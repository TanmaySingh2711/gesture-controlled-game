Obsolete endless-runner game from before the Pac-Man revision (P1).

game.py / main.py implemented a 3-lane Dino cactus runner with gravity, jumping, lane
changes and vertically scrolling obstacles. None of that has a counterpart in a maze game:
Pac-Man has no jump, no lanes and no scrolling.

Kept only as a record of the earlier design. Nothing in the project imports these files.
The active game is the Pac-Man implementation in game/.
