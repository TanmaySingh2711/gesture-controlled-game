# CNN-Based Gesture Controlled Gaming Application - machines WITHOUT an NVIDIA GPU
# Python 3.12, 64-bit
#
# The same pinned versions as cuda.txt, but with the CPU build of PyTorch. The game and gesture
# control both run on it: the recognizer uses the CPU automatically when there is no GPU and
# needs about 12-14 ms per frame, well inside the webcam's 33 ms frame interval.
#
#     pip install -r requirements/cpu.txt
#
# `python install.py` picks this file or cuda.txt for you. Retraining the model is the only task
# that still needs cuda.txt and an NVIDIA GPU.
